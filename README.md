# MentalMath [![CI](https://github.com/johnathaningle/MentalMathApp/actions/workflows/ci.yml/badge.svg)](https://github.com/johnathaningle/MentalMathApp/actions/workflows/ci.yml)

Android app for practicing mental arithmetic. Pick a difficulty and game mode, then answer questions until time runs out or you run out of lives.

## Installation

[Obtanium](https://github.com/ImranR98/Obtanium) can install and auto-update this app directly from GitHub releases:

1. Install Obtanium from [F-Droid](https://f-droid.org/packages/com.imranr.Obtanium/) or [GitHub](https://github.com/ImranR98/Obtanium/releases).
2. Open Obtanium and tap **Add App**.
3. Enter `https://github.com/johnathaningle/MentalMathApp` as the source URL.
4. Tap **Add** and then **Install** when prompted.

Obtanium will check for new releases automatically.

## Building

```
./gradlew assembleDebug
```
